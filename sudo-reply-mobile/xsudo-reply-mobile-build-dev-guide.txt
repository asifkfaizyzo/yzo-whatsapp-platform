# ============================================================
# WHEN TO RELOAD vs WHEN TO REBUILD
# ============================================================

# Usually just reload Metro:
# - changed .ts / .tsx / .js / .jsx files
# - changed screens, components, hooks or state
# - changed API/service logic that does not require native changes
#
# Rebuild the native app when changing:
# - app.json / app.config.js native configuration
# - eas.json build configuration (when it changes native build output)
# - native permissions or config plugins
# - adding/removing a native dependency
# - Firebase native configuration / google-services.json
# - app scheme, Android package or iOS bundle identifier
# - native icons, splash screen or notification configuration
# - running prebuild --clean
#
# Changing only a JavaScript API URL generally does not require a
# native rebuild, but restart Metro and ensure the runtime config
# reads the updated value.


# ============================================================
# TROUBLESHOOTING
# ============================================================

# ADB shows no device:
#   adb devices
#   Enable Developer Options and USB debugging on the phone.
#   Reconnect the USB cable and accept the debugging prompt.
#
# Android USB API calls fail:
#   adb reverse tcp:5000 tcp:5000
#   Confirm backend is running on port 5000.
#   Confirm API URL is http://localhost:5000.
#
# Metro cannot connect to the phone:
#   adb reverse tcp:8081 tcp:8081
#   npx expo start --dev-client --clear
#
# API calls fail on physical phone over Wi-Fi:
#   Do not use localhost.
#   Use the computer's current LAN IPv4 address.
#   Confirm both devices are on the same network.
#   Confirm Windows Firewall permits the backend port.
#
# App says no development build is installed:
#   npx expo run:android
#   npx expo start --dev-client
#
# Changes are not reflecting:
#   npx expo start --dev-client --clear
#
# Android native project is missing / malformed:
#   npx expo prebuild --platform android
#   npx expo run:android
#
# App opens but backend requests fail:
#   Check src/config/api.ts.
#   Check app.json -> expo.extra.apiUrl.
#   Ensure the effective API URL is correct for USB, LAN or production.
#
# EAS build fails:
#   npx expo-doctor
#   eas build:list
#   Check the full EAS build logs.
#   Verify eas.json profile names and artifact settings.
#   Verify Firebase config and signing credentials are available.
#
# IMPORTANT:
# Do not run database reset/migration-destructive commands against
# production while troubleshooting the mobile app.
